# Roadmap

This page is a living document. It changes as we learn, ship, and recalibrate.

## Now — Foundation

| Feature | Status | Notes |
|---------|--------|-------|
| Practice Mode | ✅ Live | No wallet, instant play, AI opponent |
| Solo Mode | ✅ Live | On-chain, Cartridge Controller, leaderboard |
| Multiplayer (PvP) | ✅ Live | ZK-enforced, no lying possible |
| Schizodio Collection | ✅ Live | 999 Chizos, first canonical set |
| Stats Dashboard | ✅ Live | Real-time on-chain data at stats.guesschizodio.fun |
| ZK Prover | ✅ Live | Noir + UltraHonk via bb.js, Garaga verifier |

## Next — Depth

### Community & Collections
- **Collection onboarding flow** — self-serve integration for NFT projects
- **Guessability Index** — automated trait analysis per collection
- **Community tournaments** — weekly events with leaderboard prizes
- **Discord bot** — match alerts, stats, collection rankings

### Solo Mode Evolution
- **Bosses per collection** — unique AI personalities per collection (Aggressive, Defensive, Adaptive, Greedy)
- **Difficulty tiers** — Easy → Hard → Impossible, each with different question limits
- **Speed run mode** — time-limited matches, separate leaderboard

### Collector Mode Expansion
- **Multichain support** — Ethereum mainnet, selected L2s
- **Cross-collection tournaments** — mix collections in single events
- **Lending protocol integration** — rent treasury NFTs to play
- **Floor impact dashboard** — measurable buyback correlation per collection

## Later — Scale

| Milestone | Target |
|-----------|--------|
| Partner collections | 50+ |
| Chains active | Starknet, Ethereum, selected peers |
| Revenue mix | Claim fees + lending + EGS engagement |
| Token | Only after durable thresholds met |

## What would make us slow down

- A collection loses floor faster with us than without → de-list and investigate
- Retention falls below healthy floors across iterations → product before scale
- Security event in treasury or game contracts → immediate pause, public disclosure
